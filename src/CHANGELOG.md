# Changelog

All notable changes to the **FatturaFacile Website** (`fatturafacile.eu`) will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-19

### Added
- Initial public release of the official institutional landing page (`fatturafacile.eu`).
- Multi-language client-side internationalization (`i18n`) supporting English (`EN`), Italian (`IT`), French (`FR`), and German (`DE`) via `js/translations.js` and `js/main.js`.
- Adaptive Dark and Light theme switcher with automatic OS preference detection (`prefers-color-scheme`) and `localStorage` persistence.
- Side-by-side comparison of **FatturaFacile Desktop** (Standalone USB / SQLite) and **FatturaFacile Private Cloud** (Self-Hosted Multi-User).
- Interactive **Privacy Policy & Regulatory Compliance** modal covering EU GDPR (Regulation 2016/679) and Swiss FADP / nLPD requirements.
- Interactive FAQ accordion section and community feature request workflow.
- Full SEO metadata, Schema.org `SoftwareApplication` JSON-LD structured data, Open Graph / Twitter Card tags, `robots.txt`, and `sitemap.xml`.
- Open-source repository structure and governance documentation (`README.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `CHANGELOG.md`, `LICENSE`).
