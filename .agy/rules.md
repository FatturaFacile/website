# Antigravity Rules

See [AGENTS.md](../AGENTS.md) for full project architecture, coding standards, and verification commands.

## Key Rules
- Framework: Astro 7 (SSG) with TypeScript and Tailwind CSS v4.
- Always verify changes with `npm run test:i18n`, `npm run lint`, and `npm run check`.
- Multi-language parity (IT, EN, FR, DE) is strictly enforced on all content updates.
